# LoreRelay — 最初の冒険

現行ソースの開始手順です。配布VSIXとは版が異なる場合があります。[版の確認](VERSION_TRUTH.md)

## 準備

1. VS Codeで専用のプレイ用フォルダを開きます。最初は空で構いません。
2. `LoreRelay: AI接続`（英語UI: `LoreRelay: AI Connections`）からGMの接続・ログインを済ませます。Grok Buildもログインが必要です。[接続ガイド](AI_CONNECTIONS.md)
3. `LoreRelay: Open Game UI` を開きます。同梱スクリプトを使う場合、`textAdventure.skillPath` は空欄で自動探索します。

## 世界と主人公を選ぶ

- 自分の世界: Start Hubの **世界を作りはじめる** → 種類・シード・規模・つながり・ルールを選ぶ → **プレビュー** → **この世界を使う**。採用後の **主人公を作る** から名前・人物像を入力します。
- 同梱の交易世界: Start Hubの **デモ・開発者向け** → **商人シミュレーション**。`trade-routes` が通常のシナリオ読込処理で入り、Eldaの店、500 credits、空の荷車から始まります。
- 主人公を別に作る: Start Hubの **ほかの始め方** → **主人公を新規作成**。初期の操作担当はプレイヤーです。パーティ加入は必要に応じて別に選びます。
- 保存した冒険: 同じプレイ用フォルダを開いて **続ける**。

導入文はシナリオに同梱されています。表示できてもAI接続の確認にはなりません。選択肢または自由入力を送って、GMの新しい返答を確認してください。接続エラー時は表示された接続先のログイン・モデル設定を確認します。

## 取引を一往復する

1. **行動する** → **取引**。小麦と数量を選び、見込みを読んで **確認** → **確定**。
2. **旅** → South Port → **確認** → **移動を確定**。
3. 南港で小麦を **売却**。残高と荷物が変わったことを確認します。
4. Eldaの店へ帰還。必要なら **一日を終える** で世界を1ターン進めます。

これらの操作はAIを呼びません。市場間移動は画面の説明どおり即時で、日数・世界ターン・食料を消費しません。日送りは別操作です。価格や在庫は世界の進行で変わります。[交易ガイド](LIVING_WORLD_QUICKSTART.md)

## 記録と画像

- **チェックポイント** を押し、任意の名前を付けて保存します。通常の状態変更もプレイ用フォルダへ保存されます。
- **ワールド** → **シーン画像** は現在地のComfyUI生成候補です。完成するとその場所の **シーン履歴** に出ます。移動先の背景やGMの記憶へ自動的に移すものではありません。
- 外部AIを使いたい場合は [この場面を絵にする](VISUAL_COMPOSER_V1.md)。人物・地図・拠点資料との違いは [ComfyUI実運用ガイド](COMFYUI_LOCAL_PLAYCHECK.md) にまとめています。

描写を直すときは本文編集や自由入力の訂正、長く残す設定はロアブックの固定を使えます。「戻る」は会話を戻して現在の資産・場所・依頼を保持します。ゲーム全体を戻したい場合は、操作前に保存した完全チェックポイントを復元してください。Campaign等の「再生成」は確定済み行動の再送を防ぐため停止します。[訂正・再起動・Undoの実機確認と制限](RECOVERY_PLAYCHECK_2026-09-20.md)

[1.89.3の交易・画像確認](GAMEPLAY_PLAYCHECK.md)はGrokの再ログインが必要で新規GM会話を確認できなかった時点の記録です。その後の[1.89.4のCodex GM・依頼完了](REAL_GM_PLAYCHECK.md)、[1.89.5の人物と信頼報酬](NPC_IDENTITY_PLAYCHECK.md)は別の実機記録として参照できます。いずれもAI操作であり、ユーザー本人のHuman Playとは区別します。
