# イラスト地図をゲームで使う

ワールド画面の「画像を取り込む」で PNG・JPEG・WebP を選びます。地名・地点・経路を重ねたプレビューを見て「この世界に採用」を押すと、ゲーム内の「イラスト地図」に反映されます。外部AIへのプロンプト出力後にも取り込み操作を選べます。

「位置を調整」で地点ピンと地域名をドラッグし、「保存してゲームに戻る」で保存します。「自動配置に戻す」は編集内容を初期配置に戻し、保存するまでは確定しません。「キャンセル」で編集中の変更を破棄できます。地名と経路の表示は個別に切り替えられます。フィットは画像全体を表示し、拡大後は背景のドラッグまたはスクロールで移動できます。

画像に描かれた道とゲームの移動経路は一致するとは限りません。調整するのは表示位置だけです。ゲームの移動関係・現在地・未発見地点の公開範囲は既存ルールに従います。近接したピンが重なる場合は、手前のピンを動かしてから奥のピンを調整できます。

## 主人公マーカーと地名

現在地は金色の丸い人型マーカーで表示します。「アイコン画像を設定」から PNG・JPEG・WebP（最大4 MiB）を選ぶと、主人公の画像に切り替わります。「主人公マーカー」で「標準（人型）」と「設定した画像」をいつでも選び直せます。標準に戻しても設定画像は残り、同じ世界の地図を差し替えても引き継ぎます。画像未設定でも標準マーカーを使えます。

通常表示の地名はピンを避ける位置に表示し、ピンより前面に描画します。「位置を調整」中は保存する基準位置をそのまま表示します。読みやすさのための表示調整は、保存座標・経路・ゲームの移動条件を変えません。

## 手持ちモデル

「手持ちモデル」→「フォルダを登録」で ComfyUI、Stability Matrix またはモデルフォルダを指定します。共有モデルが別の場所にある場合は、そのフォルダも登録してください。Stability Matrix の `StableDiffusion` と ComfyUI の `checkpoints` をチェックポイントとして読み、共有フォルダの重複と循環を除外します。

ローカルの `.cm-info.json`、`.civitai.info` などからベースモデルを判定し、ComfyUI の一覧が取得できれば照合します。停止中・未接続・信頼されていないワークスペースでは実行可否を未確認として表示します。モデルのダウンロードは行いません。

SDXL Canny / Direct を選び「このモデルを使う」で保存した後、「イラスト地図」の「選択したモデルで生成」を使います。チェックポイント、系統、プロンプトモードは共通の画像生成設定にも反映されます。Anima、LoRA、判定が矛盾するモデルなどは地図用チェックポイントとして採用できません。互換性の判定は画質や地図への適性を保証するものではなく、必要な ControlNet などの設定・生成前検証も引き続き必要です。

## 保存と互換性

採用画像と表示設定はワークスペース内の `.lorerelay-map-assets` に保存します。元画像は変更しません。世界ごとの設定を画像ハッシュと結びつけ、差し替え時に以前の設定を退避します。新しい画像の位置調整は初期配置から始まります。旧形式の `world_map.png` も表示でき、位置調整を開始すると新しい保存形式へコピーします。

対応画像は最大32 MiB、4000万画素、各辺16384ピクセルです。画像をデコードできない場合はプレビューから採用できません。保存失敗や古い編集画面からの保存はエラーを表示し、以前の採用状態を維持します。生成中に世界や採用地図が変更された場合は、自動採用せず生成ファイルを手動取り込み用に残します。
