# 思い出と約束 — 1.91.0

会話の「記録・訂正」から、一回だけの作者メモ、固定Lorebook、描写の訂正、手動の思い出・約束を作れます。「思い出と約束」で自動記録／確認して採用を切り替え、根拠を開き、編集・取り消し・人物の対応付けを行います。同名人物は自動統合しません。正式NPCの既存記憶も同じ一覧に表示します。

`game_state.json` の任意の `narrativeMemory` に記録します。GMは通常応答の `narrativeMemoryProposals` に正確な引用を含む候補を返します。Hostが採用された応答だけに安定IDと根拠・会話のアンカーを割り当てます。非対応接続では手動記録を利用できます。候補の不正は通常応答を止めません。

保存済みのゲーム状態、プレイヤーの設定・訂正、採用済み記録、通常履歴の順で扱います。訂正対象の原文は残し、その発言を履歴検索から外します。記憶全件を毎回送らず、人物・場所・未解決の約束を既存の予算内で優先します。モデルが指示に完全に従うことは保証しません。

会話Undoはその応答をアンカーとする記録・更新も戻し、資産・所在地・依頼を保持します。固定Lorebookは別管理です。全状態チェックポイントと分岐保存では記録を含めて復元します。本文を編集して根拠が変わると確認待ちへ戻ります。約束の期限は世界時間のみで判定し、超過しても破棄にはしません。約束の状態は金品・信頼度を変更しません。

再開カードは保存状態と現存する会話に対応するChronicleの移動・依頼だけを読みます。AI呼び出しも時間進行もありません。未公開のディレクター場面や将来の行動は表示しません。

## 短い検証用冒険

`resources/browser-start/reunion-three-people.json` を `LoreRelay_Start.bat` で開いてください。ミナ（カフェ）、レン（灯台）、トワ（船着場）の3人と出会い、それぞれと約束し、離れ、VS Codeを閉じて同じ冒険を再開し、再会します。会話だけの人物として始めるため、勝手なNPC登録も確認できます。正式NPCとの照合は登録済みNPCを持つ既存冒険で人物の対応付けを使います。

1. ミナへ「風鈴を返す」、レンへ「星の観測を一緒にする」、トワへ「旅の話を聞かせる」と自分で約束する。
2. 別の話題を20ターン続ける。会話回数だけでは期限・世界時間が進まないことを確認する。
3. 再起動して再会し、思い出と未解決の約束が会話へ出るかを確認する。
4. 自動／確認方式、同名の別人、本文編集、Undo、完全チェックポイント、分岐を試す。依頼されただけの内容がプレイヤーの約束になっていないか確認する。

Before planning verification, follow `docs/DEVELOPMENT_VERIFICATION_POLICY.md`. Do not escalate beyond its risk tier without a concrete reason.
