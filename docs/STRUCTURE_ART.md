# 拠点・車両を絵にする

固定拠点・移動拠点の「この拠点を絵にする・画像を見る」、車両詳細の「この車両を絵にする・画像を見る」から開きます。外観、または配置のある階層の内装を選べます。

1. 「見た目の希望を編集」で材質・色・装飾・画風・追加要望を入力します。空欄は未指定です。
2. 「資料を保存」で説明文 `brief.md`、番号付き設計図PNG、斜め上からの参考PNG、作成対象を記録したmanifestを出力します。外観では全階層、内装では選択階層を出力します。配置がない車両は文章のみです。
3. 「説明文をコピー」と「保存先を開く」を使い、外部画像AIへ文章とPNGを手動で添付します。資料を保存しただけでは外部送信されません。
4. 「完成画像を取り込む」でPNG・JPEG・WebPを選び、対象と画像を確認して採用します。読み込めない画像は採用できません。
5. 採用後は元の画面に戻ります。「画像を見る」から外観／階層別内装を切り替え、画像クリックで拡大できます。「設計図・集落表示に戻る」で閉じます。

施設番号は資料の一覧と対応します。配置図には既存表示の自動配置を含むため、実寸の建築図面ではありません。普通の車両に架空の間取りや寸法を確定情報として追加しません。車両と連携する移動拠点は同じ画像セットを使います。

元画像を変更せず、`.lorerelay-structure-art` に対象世界・拠点／車両別に保存します。差し替え前の採用画像は履歴に保持します。配置や仕様が変わった画像には旧資料の表示が出ます。再生成は自動ではなく、資料を出し直して行います。ゲームの施設や移動条件は画像から変更されません。

## 家族向けデモ

既存Sapphire Roadsの港で船を選び、外観用の資料を出力します。甲板・船倉の設計図と斜め上PNGを外部AIに添付し、完成画像を外観に取り込みます。内装も階層ごとに同じ操作を行えます。

実装確認では、6固定拠点の番号対応、保存・差し替え・再読込・世界分離・古いプレビュー・保存失敗を自動テストし、二層の川船の4枚のPNG出力と画像デコードをheadless Edgeで確認します。代替画像による取り込み確認は外部AI生成の成功と区別します。ネイティブVS Codeの実演結果は別途記録します。
