# 3世界の拠点ジオラマ確認

2026-09-15 / 1.88.3候補。ファンタジー《鐘のねぐら》《灯し尾》、SF《灯台七号》《ミナモ》、ポストアポカリプス《第八休憩所》《雨つばめ》を専用workspaceに事前配置した検証です。既存の冒険は変更していません。

![本番Webviewによる3世界のジオラマ](assets/three-world-diorama/overview.png)

## 確認できたこと

- 本番 `pushWorldViewToWebview` から固定拠点と移動拠点のスナップショットを取得し、既存Three.js描画へ渡しました。固定／移動拠点、地上／上階を切り替えて対象IDを照合しました。
- マウスドラッグによる回転、拡大ボタン、マーカーの詳細表示をブラウザで確認。描画時のJavaScriptエラーは0件でした。
- 壁は高さのあるブロック、門は薄い板、水面は低い青色タイル、施設は用途別ブロックとして表示されます。日本語ラベルの施設が床扱いになっていた不具合を修正しました。
- `expand_layer` をホストの保存処理へ渡し、ルートの移動拠点に `z-1` を追加できること、再送で二重に追加されないこと、固定拠点の配置が変わらないことを確認しました。検証後、デモの開始配置を復元しています。
- 固定拠点のGM要約がルート移動拠点を参照する問題を修正。現在地に対応する固定拠点を解決し、正常な施設名、階層、公開済みの入口・配置を要約します。移動拠点の公開済み階層もGMへ渡します。
- Grok 4.6の実接続で3世界の送信前後コンテキストを照合。固定拠点名・入口・施設・移動拠点と、移動拠点への `z-1` 追加を回答できました。AIの回答は候補であり、ゲーム状態へ適用していません。

## まだできないこと・今回の限界

| 項目 | 現状 |
|---|---|
| 建物の外観 | 屋根や窓を持つ建築模型ではなく施設ブロック |
| 道・桟橋・着陸区画 | 床タイルとラベル。専用の模型なし |
| 給水機械・階段 | ラベル／マーカーで位置を表現。専用模型なし |
| 二階建て | 階ごとの切替。上下階を積んだ完成建物ではない |
| 配置の自由度 | 既存形式の座標付き区画。区画上限40、ビューは16または24の正方形。任意の建築CADではない |
| 新施設の建設 | 汎用の建設エディタや施設追加操作は未実装。今回の建物は事前配置 |
| 階層拡張の対象 | ルート `settlement_layout.json`。街ごとのscoped拠点を選択して建設する経路ではない |
| 資源消費 | 今回の階層拡張には消費の適用なし。消費確認済みとは扱わない |
| GMの情報量 | 上限付き要約。全間取りを無制限に渡すわけではない。Grokは未記載を「ない」と言い切る場面もあり、未確認と不存在は区別が必要 |
| ネイティブ実機 | 通常のVS Code実機操作・人間のHuman Play・再起動操作は未確認 |

`settlementOps` のうち保存されるのは階層拡張です。その他の在庫・施設注記などは解析のみです。`mobileBaseOps` の停泊・離脱・移動・燃料消費は既存車両保存経路を持ちますが、今回新たに航行・燃料操作の実プレイを行ったものではありません。
