# 水系・船・橋・渡し場（1.88.0 コード候補）

新規生成した地上世界の水系を、地図と移動で共用します。既存世界を自動変換しません。宇宙テーマは従来の生成を保ち、宇宙航路の危険判定は含みません。

## 遊び方

1. ワールドの「航路・渡河」を開く。
2. 徒歩か所有船・車両、発見済みの目的地を選び「経路を確認」。他人の船や別の場所にある船は使用できません。
3. 安全な経路が優先されます。「危険な近道を確認」があれば比較できます。距離はゲーム内の世界座標単位です。
4. 損傷がある場合は表示された船体HPの変化を確認し、チェックを入れて出発。確認後に世界・現在地・船の状態が変わると再確認になります。
5. 出発後はゲームの現在地、船の所在地、船体HPが保存されます。徒歩を明示的に選ぶと乗り物は出発地に残り、選択中の乗り物を解除します。通行不可から徒歩へ自動切替はしません。

水系を持つ世界では、従来の市場直接移動もこの画面へ案内します。AIの文章や旧車両操作だけで船を移動させることはできません。車両なしの旧徒歩移動は同じ道路・渡河判定に通った場合だけ保存できます。

1.88.2では、別々の港が同じ水系ノードを参照する場合は「個別の水上接続を設定」と表示して出発を止めます。接続区間がないため、距離や安全性を推測しません。チェックポイント復元と新規開始はホストの明示した公開操作として通常移動から分離し、未完了の航行は先に復元します。

図解・タイル・イラスト地図の水系表示と外部AI向け下絵は同じ世界座標を使用します。倍率0.75×で大河、1×で河川以上、2×以上で小河川を表示。選択した経路は倍率に関係なく表示します。未発見領域の水路・橋・地名は倍率を上げても公開しません。イラストの川自体から航路を推測する機能はありません。

## データの意味

`world_forge.json` の `geography.waterways` は生成時に確定し、保存・再読込されます。seedと生成方式version 1から128×128の標高傾向、窪地処理、流下方向と集水量を生成。川の有向接続は上流から下流を示します。船は能力があれば上下どちらへも航行できます。

川の規模は `stream / river / major`。支流・本流は接続関係であり、規模とは別です。川幅と水深はそれぞれ1〜3のゲーム区分。海域は `coastal / ocean` と `seaRows` の1/2で保存し、シナリオに保存された明示指定は読み込み時に再分類しません。自動生成時は陸から8セル以内を近海とします。道路と川の交点は生成時に橋／渡し場として記録し、描画だけの交差は移動条件に使用しません。

船の `waterProfile` 例：

```json
{"width":2,"draft":1,"airDraft":2,"seaworthiness":0}
```

`width` は船幅、`draft` は喫水、`airDraft` は船高（橋の桁下と照合）。それぞれ1〜3。`seaworthiness` は0＝内水、1＝近海、2＝外海。総合サイズから既存船の性能を推測しません。新しい船を設定するときはこれらを明記してください。未設定なら水上航路は出発不可です。デモの小舟・川船・大型浅喫水船・帆船・近海船・外洋船には個別に設定済みです。

橋の陸上通行には車両の `crossingProfile: {"width":2,"load":2}` を使用。徒歩には車両条件を課しません。渡し船は `maxVehicleSize` に対して既存の `tiny / small / medium / large / huge / colossal`（0〜5）を照合します。橋の破損、跳ね橋、運航時刻、料金は今回含みません。

航続距離は既存 `rangeBand` の local=250、regional=750、long=2000、very_long=上限なしを使用。実距離のメートル換算、燃料消費、時間経過は追加しません。

耐航性が1段階不足する**連続海域**を通ると、最大船体HPの5％（切り上げ）の損傷。128グリッドの細かな辺ごとに損傷を重ねません。安全区間を挟んで再び危険海域に入ると、別の危険区間として再度加算します。2段階不足は通行不可。予告損傷でHPが0以下になる経路は出発できず、この機能だけで沈没・消失させません。

## 保存と復元

`.water-navigation.json` に対象世界のハッシュ、保存前後、要求IDを記録してから `game_state.json` と `vehicle_state.json` を置換します。commitマーカー前の失敗・再起動は両方を復元。commit後の要求再送は再適用しません。既存の `.bak` と車両v2の既存receipt情報を変更しません。

復元途中に別の世界や第三者によるセーブ変更を検知した場合、自動上書きを止めます。エラー表示を確認し、journalとセーブを保全してください。通常のファイル保存と同じく、物理的なディスク故障を越える保証はありません。

## 家族向けデモ

コンパイル後、**空の新規フォルダ**を指定します。既存データ入りフォルダでは実行を拒否します。

```powershell
node scripts/create_water_navigation_demo.js C:\AI\LoreRelay-Water-Demo\workspace
```

`generated-world-reference.json` は同じseedで生成した原本、実演用の `world_forge.json` は条件を比較しやすく設計した専用シナリオです。全域公開はこのデモだけの設定です。実冒険や人間プレイの記録ではありません。

5分程度の実演例：

| 操作 | 見せたいこと |
|---|---|
| 図解を0.75×→2×へ | 大河だけの全体像から細い支流へ |
| 川船で「山あいの支流」を確認 | 川幅不足。出発できない |
| 小舟で同じ目的地を確認 | 狭い支流を通れる |
| 大型浅喫水船で「大河の河口」を確認 | 大きさだけでなく喫水で判定 |
| 帆の高い船で同じ目的地を確認 | 低い橋が障害になる |
| 川船で「近海の港」を確認 | 安全な内水迂回を優先。危険な近道はHP100→95 |
| 損傷を確認して近海の港へ出発 | 現在地と船体HPが更新される |
| 港にある近海船で「外海の島港」を確認 | 安全な沿岸迂回と危険な外海近道の比較 |
| 港の外洋船に切り替えて同じ目的地 | 外海を安全に航行できる |

資料PNGを外部AIに渡して新しい地図を作り、既存の「画像を取り込む」で重ねることもできます。外部AIでの画像生成は利用者が行います。今回の検証は水系・移動機能であり、外部生成成功を主張するものではありません。
