広場の中心で、アレンの言葉を思い返す。エロウェン隊長は訓練場か詰所にいる可能性が高い。

まだ移動は行わず、移動UIを開いて行き先一覧を確認しよう。そこに「訓練場」または「詰所」が表示されていれば、隊長に会う目的地として選べる。表示されない場合は、アレンに現在の隊長の所在をもう一度尋ねるのが確実だ。

{

      "id": "turn-6",
      "role": "gm",

    }
  ],
  "options": [
    "移動UIで行き先一覧を確認する",
    "訓練場が表示されていれば選択する",
    "アレンに隊長の所在を尋ねる"
