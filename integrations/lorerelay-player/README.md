# LoreRelay Player plugin source

This plugin provides the playing instructions. The source MCP configuration is empty:
connection settings belong to an expiring Host session, never to the published package.
Use LoreRelay's **AI Connections** command to generate the current client configuration
and approve the campaign/session in the Host. Do not commit that configuration.

The packaging/export step that combines the local adapter with this source is still
under implementation. This source alone is not evidence of a connected client.
