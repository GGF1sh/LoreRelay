# 九江門 — 論剣会まで三月

五大門派の均衡の下、最下位の中堅門派に入門した。三月後の論剣会で負ければ、門派は吸収される。二十年前に消えた秘籍〈斷水譜〉の噂が流れはじめた。

> **これは advanced / manual サンプルです。** Start Hub にはまだ配線されていません。

## 遊び方

1. VSCode で空のゲーム用ワークスペースを開く
2. `Ctrl+Shift+P` → **`LoreRelay: Load Scenario Pack`**
3. このフォルダ（`sample-scenarios/nine-rivers-sect`）を選択

## 主人公について

- 空のワークスペースでシナリオを読み込むと、既存の `setup.playerCharacter` 機構により**推奨デフォルト主人公（陸小澄・九江門の新弟子）が自動的に作成・Active・party登録**されます。すぐに遊び始められます。
- これは**固定の主人公ではなく、遊びはじめやすくするための一例**です。気に入らなければ、Character Creator からいつでも編集・置換・新規作成できます。
- 既にプレイヤーキャラクターが存在するワークスペースで読み込んだ場合、既存のキャラクターは**上書きされません**（既存の仕組みがそのまま働きます）。

## 世界NPCについて

**柳青鸞**（九江門の首席弟子）と**陳阿七**（門派の厨房番）は `npc_registry.json` に登録された世界側NPCです。**主人公のテンプレートではありません。** 掲示板の噂話やGMとの対話の中で、二人ともシナリオを通して自然に登場します。

画像を生成したい場合は `IMAGE_PROMPTS.md` を参照してください（ComfyUI用パラメータ／ChatGPT・Grok・Gemini向け自然文プロンプトの両方を収録）。

## 人間プレイで確認したいこと

- GM が柳青鸞・陳阿七それぞれの性格を、`npc_registry.json` の `personalityTraits` / `dialogueHints` に沿って一貫して維持するか
- 推奨主人公（陸小澄）のまま遊んでも、Character Creator で作り直しても、物語として成立するか
- 三月（90日）という時間制限が、単なる文章上の設定で終わらず、実際のプレッシャーとして感じられるか
- 修行・〈斷水譜〉の噂・門派間の対立が、GM側から自然な選択肢として出てくるか

このシナリオは、上記の人間プレイでの確認が済むまで「完成」とは見なしません。
