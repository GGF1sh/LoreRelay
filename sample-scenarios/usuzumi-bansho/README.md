# 薄墨番所 — 暮れ六つの入れ替わり

街道の宿場町で、暮れ六つを過ぎると人が入れ替わる。幕府が置いた三人だけの番所に、あなたが四人目として配された。

## 遊び方

このシナリオは Start Hub には配線されていません。以下の手順で読み込んでください。

1. VSCode で空のゲーム用ワークスペースを開く
2. `Ctrl+Shift+P` → **`LoreRelay: Load Scenario Pack`**
3. このフォルダ（`sample-scenarios/usuzumi-bansho`）を選択

主人公は **Character Creator でゼロから作成**するのが基本です。雰囲気をつかみたい場合は、同梱の `characters/` フォルダに2人分の設定キャラ（SillyTavern Character Card v2形式）が入っています。シナリオ読込時に自動的に取り込まれ、Character Profile タブから選んで Active にできます。気に入らなければ、いつでも Character Creator で自分のキャラを新規作成できます。

画像を生成したい場合は `IMAGE_PROMPTS.md` を参照してください（ComfyUI用パラメータ／ChatGPT・Grok・Gemini向け自然文プロンプトの両方を収録）。
